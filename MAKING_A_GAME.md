# Making a Game

The guide to building your own game on the engine has moved to the `docs/` folder:

**[docs/MAKING_A_GAME_GUIDE.pdf](docs/MAKING_A_GAME_GUIDE.pdf)**

It takes you from the minimal starter in `games/starter/` (which boots and quits) to a game with its own state, subsystems and art, and lists the lines to add for each optional engine subsystem: entities, crates, water and VHS rewind.

Use it alongside [`engine/ENGINE_CONTRACT.md`](engine/ENGINE_CONTRACT.md), the reference for every hook, binding and buffer a game must supply. The other companion guides (PDF) are in [`docs/`](docs/).
